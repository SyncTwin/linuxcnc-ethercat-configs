# Светофор: три шага по таймерам

Самая простая последовательность SFC: красный → зелёный → жёлтый → снова красный.
Каждый шаг держится, пока не выйдет его время. Время каждого цвета — ручка программы
(`VAR_INPUT ... : TIME`), её можно менять на ходу.

```bash
sudo apt install linuxcnc-uspace
cd sfc-on-hal/traffic_light
halrun -f run_demo.hal
```

## Файлы

| файл | что это |
|---|---|
| `traffic_light.sfc` | программа текстом SFC (МЭК 61131-3) |
| `traffic_light.clp` | та же программа для ClassicLadder: Grafcet + рунги; напечатан из `.sfc`, комментарии переведены |
| `traffic_light.hal` | поток 1 мс, ClassicLadder, проводка входов и ламп |
| `run_demo.hal` | сценарий: разрешение → два круга → удержание на 2 с |
| `run-log.txt` | настоящий вывод `halrun -f run_demo.hal`, убраны только служебные строки |

## Что где

| элемент SFC | ClassicLadder | пин HAL |
|---|---|---|
| шаги red, green, yellow | Grafcet `%X1…%X3`, активность рунгом на `%Q0…%Q2` | `classicladder.0.out-00…02` |
| `red.T >= t_red` | таймер `%T` (основа 100 мс), уставка = ручка / 100 каждым тактом | — |
| ручки `t_red`, `t_green`, `t_yellow` | `%IF0…2`, в миллисекундах | `setp classicladder.0.floatin-00…02` |
| лампы | SET/RESET катушки `%Q3…%Q5` | `classicladder.0.out-03…05` |
| удержание | размыкающий контакт `%I1`: переходы стоят, время шага на паузе | `classicladder.0.in-01` |

## Попробуйте

- `setp classicladder.0.floatin-01 6000` после `start` — зелёный горит 6 с, к отметке
  t=6.5 светофор всё ещё зелёный.
- Уставка считается по 100 мс: время короче 100 мс или не кратное 100 мс таймер не различит.
- Удержание (`sets hold 1`) ставит время шага на паузу, а не сбрасывает его: в логе
  красный после снятия удержания догорает оставшиеся секунды.

## Честные пределы

- В `traffic_light.hal` массивы пинов `numS32in`, `numS32out`, `numFloatOut` равны 1, хотя
  программа их не использует. С нулём `classicladder_rt` роняет HAL на первом такте
  (Debian 12, `linuxcnc-uspace` 2.9.0~pre1, проверено 02.10.2026).
- Прогон снят без RT-ядра: он доказывает логику последовательности, а не джиттер.

# Бак: налить, перемешать, слить

Учебная задача SFC: по кнопке «Пуск» открыть впускной клапан, налить до верхнего датчика
уровня, закрыть клапан и мешать `t_mix`, затем слить до опустошения и ждать новой кнопки.

```bash
sudo apt install linuxcnc-uspace
cd sfc-on-hal/tank
halrun -f run_demo.hal
```

Датчики уровня не моделируются: сценарий ставит их руками (`sets level-high 1`).

## Файлы

| файл | что это |
|---|---|
| `tank.sfc` | программа текстом SFC (МЭК 61131-3) |
| `tank.clp` | та же программа для ClassicLadder; напечатан из `.sfc`, комментарии переведены |
| `tank.hal` | поток 1 мс, ClassicLadder, проводка датчиков и клапанов |
| `run_demo.hal` | сценарий одной партии |
| `run-log.txt` | настоящий вывод `halrun -f run_demo.hal`, убраны только служебные строки |

## Что где

| элемент SFC | ClassicLadder | пин HAL |
|---|---|---|
| шаги idle, fill, mix, drain | Grafcet `%X1…%X4`, активность на `%Q0…%Q3` | `classicladder.0.out-00…03` |
| `start_edge(CLK := start)` | контакт по фронту `%I1` в шаге idle | `classicladder.0.in-01` |
| `level_high`, `NOT level_low` | контакты `%I2`, `%I3` (размыкающий) в переходах | `in-02`, `in-03` |
| `mix.T >= t_mix` | таймер `%T0`, уставка из ручки `%IF0` (мс) | `setp classicladder.0.floatin-00` |
| клапаны и мешалка | SET/RESET катушки `%Q4…%Q6` | `out-04…06` |

## Попробуйте

- `setp classicladder.0.floatin-00 6000` после `start` — бак мешает 6 с и к концу
  сценария всё ещё в шаге mix.
- Уберите из сценария `sets level-high 1` — бак останется в шаге fill с открытым клапаном.
  Защиты от перелива в программе нет, это задача отдельной блокировки.

## Честные пределы

- Массивы пинов `numS32in`, `numS32out`, `numFloatOut` в `tank.hal` равны 1: с нулём
  `classicladder_rt` роняет HAL на первом такте (проверено 02.10.2026).
- Прогон снят без RT-ядра: логика, а не джиттер.

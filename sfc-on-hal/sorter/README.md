# Сортировка: выбор ветви и счётчик брака

Деталь доезжает до датчика и останавливается. Если сработал датчик высоты, толкатель
сбрасывает её в корзину брака, иначе лента везёт её дальше. После трёх бракованных деталей
линия стоит с лампой «корзина полна», пока оператор не подтвердит, что корзину освободил.

Здесь две развилки выбора (альтернативные ветви SFC) и счётчик CTU.

```bash
sudo apt install linuxcnc-uspace
cd sfc-on-hal/sorter
halrun -f run_demo.hal
```

Датчики не моделируются: сценарий ставит их руками.

## Файлы

| файл | что это |
|---|---|
| `sorter.sfc` | программа текстом SFC (МЭК 61131-3) |
| `sorter.clp` | та же программа для ClassicLadder; напечатан из `.sfc`, комментарии переведены |
| `sorter.hal` | поток 1 мс, ClassicLadder, проводка датчиков, ленты, толкателя, лампы |
| `run_demo.hal` | сценарий: нормальная деталь, три высокие, корзина полна, корзину освободили |
| `run-log.txt` | настоящий вывод `halrun -f run_demo.hal`, убраны только служебные строки |

## Что где

| элемент SFC | ClassicLadder | пин HAL |
|---|---|---|
| шаги wait_part, check, reject, pass, bin_full | Grafcet `%X1…%X5`, активность на `%Q0…%Q4` | `classicladder.0.out-00…04` |
| выбор `check → reject` / `check → pass` | два перехода из одного шага, условия `tall` и `NOT tall` | `in-02` |
| выбор `reject → wait_part` / `reject → bin_full` | условия `NOT rejects.Q` и `rejects.Q` | — |
| `rejects : CTU`, PV = 3 | счётчик `%C0`, CU — шаг reject, R — шаг bin_full | — |
| лента, толкатель, лампа | SET/RESET катушки `%Q5…%Q7` | `out-05…07` |

## Попробуйте

- Подайте `sets bin-emptied 1` до того, как корзина заполнилась, — ничего не произойдёт:
  этот вход читает только переход из шага bin_full.
- Новая деталь, пока корзина полна, в логе игнорируется: шаг wait_part не активен, и фронт
  датчика никто не ловит.

## Честные пределы

- Условия ветвей выбора написаны взаимоисключающими. Явного приоритета ветвей, который
  допускает МЭК, у этого исполнителя нет; на порядок срабатывания двух истинных переходов
  не полагайтесь.
- Массивы пинов `numS32in`, `numS32out`, `numFloatIn`, `numFloatOut` в `sorter.hal` равны 1: с нулём
  `classicladder_rt` роняет HAL на первом такте (проверено 02.10.2026).
- Прогон снят без RT-ядра: логика, а не джиттер.

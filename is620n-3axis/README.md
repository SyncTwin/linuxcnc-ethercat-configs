# Три оси IS620N в режиме CSP плюс дискретное IO

Конфигурация нашего стенда целиком: каплер Omron NX-ECC202 с модулями дискретного
вывода и три сервопривода Inovance IS620N на осях X, Y, Z.

## Файлы

- `ethercat-conf.xml` — описание шины для драйвера `lcec`
- `machine.hal` — загрузка `cia402.comp` на три оси, связка с motion, съём телеметрии

## Как устроено

Каплер описан как `type="generic"`: отображение PDO расписано руками, объект за
объектом. Приводы описаны как `type="basic_cia402"`: стандартные объекты профиля
драйвер отображает сам.

Смешивать эти два способа в одной шине можно, и здесь так и сделано. Ручное описание
берут там, где нужен полный контроль над картой, готовый тип — там, где устройство
укладывается в профиль.

У приводов включены дополнительные объекты сверх обязательных:

```xml
<modParam name="enableActualTorque" value="true"/>
<modParam name="enableActualFollowingError" value="true"/>
```

Момент нужен для поиска касания по нагрузке, отставание — чтобы видеть, насколько
привод не поспевает за командой. Оба приходят каждый такт, отдельных датчиков для
этого не требуется.

Синхронизация: `assignActivate="300"`, `sync0Cycle="*1"` — импульс каждый цикл,
период мастера 1 мс (`appTimePeriod="1000000"`).

## Грабли

**Один передающий PDO.** IS620N назначает ровно один TxPDO: либо `0x1A00`, либо один
из `0x1B01…0x1B04`. Индекса `0x1A01` у привода нет. Если попытаться добавить второй
PDO, обмен вернёт ошибку и слейв не дойдёт до OP. Всё нужное кладётся в `0x1A00`, у
него переменное отображение до десяти записей.

**Ошибка `Er.E08`.** Возникает, когда мастер пропадает, пока привод находится в OP.
Снимается только полным перезапуском питания привода, сброса ошибки недостаточно.
Если она приходит посреди нормальной работы, а не при остановке мастера, смотрите
счётчики ошибок на портах: это физика линии, а не профиль.

**Невыход в OP.** Чаще вызван задержками реального времени, а не настройкой профиля.
Прогоните `cyclictest` до того, как трогать XML. У нас на разгруженной машине пик
15 мкс, и при таком запасе приводы держат OP устойчиво. На перегруженной в логе
появлялось `Unexpected realtime delay on task 0 with period 1000000`, и приводы
отваливались по одному.

**Имя слейва пустое.** Привод не сообщает название прошивки, поэтому опознавать
модель нужно по идентификаторам из `0x1018`: `vid=0x00100000`, `pid=0x000C0108`.

## Масштаб оси

В нашей механике ШВП с шагом 10 мм и энкодер 23 бита:

```
8388608 / 10 = 838860.8 импульса на миллиметр
```

Распространённая ошибка — взять 2 097 152. У вас другая передача, считайте своё
число. **Проверьте его до первого большого перемещения.**

## Замеренное на этой конфигурации

Отставание оси пропорционально скорости и одинаково у всех трёх осей:

| подача | скорость | отставание (p95) |
|---|---|---|
| 3000 мм/мин | 50 мм/с | 1,34 мм |
| 750 мм/мин | 12,5 мм/с | 0,34 мм |
| покой | 0 | 0 |

Отношение скорости к отставанию около 37 с⁻¹. Настройки контуров заводские,
упреждение по скорости не трогали: это поведение из коробки, а не предел привода.

На прямой такое отставание в геометрию не выходит, все оси отстают одинаково и меняется
только фаза. Срез появляется на углах и дугах.
